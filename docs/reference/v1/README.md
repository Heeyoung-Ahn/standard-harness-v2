# Standard Harness v1 Reference Archive

This directory stores reference-only material from the currently used v1 harness.

`clean-starter-harness.zip` is not the v2 source of truth and must not be copied into
`starter/standard-harness/` or promoted into v2 runtime surfaces as-is. Use it only to
compare behavior, extract reusable principles, and design v2-native implementations
that align with the requirements and architecture contracts in this repository.
