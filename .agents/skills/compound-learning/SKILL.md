# Compound Learning

Use this skill after solving a recurring or likely-to-recur problem whose lesson should be captured for future work.

## Use When
- A bug, review finding, operator confusion, failed verification, or repeated workflow friction has a reusable lesson.
- The same root cause could affect future packets or projects.
- The user asks to preserve learning or preventive memory.

## Do Not Use When
- The item is one-off noise with no reusable trigger.
- The lesson would expose secrets, private data, or project-specific confidential details.
- The entry would become a new authority that overrides packets, requirements, or review evidence.

## Workflow
1. Identify the symptom.
2. Identify the root cause.
3. State the reusable trigger that should activate the lesson later.
4. State the preventive check or rule.
5. Record source evidence and limitations.
6. Route any durable memory change through the approved learning or preventive-memory surface.

## Evidence To Produce
- Symptom, root cause, trigger, preventive check.
- Source references.
- Memory destination or note-only rationale.

## Authority Boundary
This skill captures reusable learning. It must not create approval, override source artifacts, expose secrets, or mutate long-term memory without the approved learning route.
